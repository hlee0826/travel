# Reference-library QA review

Date: 2026-11-09  
Design-system version: 1.2

## Scope

These are fictional composition references, not commissioned likenesses. They cannot pass the project's formal identity gate because there is no real-pet reference set or familiar-person reviewer. They must not be presented as approved customer portraits. Their purpose is to validate pose, garden integration, material treatment, and interaction logic before the method is applied to an identity-approved pet.

## Set checks

- [x] 10 dog images and 10 cat images
- [x] Each species: 3 peony, 3 lotus, 2 plum, 2 pine
- [x] Ten distinct pose skeletons per species
- [x] Pet remains the first focal point at thumbnail size
- [x] Pet and garden share hanji, pigment, contour, and barim treatment
- [x] Shallow symbolic space; no photographic horizon
- [x] Butterfly or magpie participates in a legible gaze/gesture relationship
- [x] Motifs avoid eyes, muzzle, defining markings, paws, and tail
- [x] Pine plates use pine, rock/water support, and one magpie without unrelated flowers
- [x] No pet name, Korean or Latin text, seal, signature, watermark, border, or app UI
- [x] All accepted files are 1122 × 1402 RGB PNG

## Known limitations

- Exact butterfly count is a soft reference variable; the model occasionally creates an additional small butterfly. Commission prompts should enforce count during concept QA and remove extras in revision.
- These plates demonstrate fictional individuality through explicit anchor descriptions, not verified likeness. Commission use still requires intake, an undecorated identity study, all four likeness tests, approval, and then motif integration.
- Print color and paper behavior have not been proofed.

## Acceptance status

Accepted as an experimental composition-and-rendering reference library. Not approved as a substitute for the commissioned portrait workflow or the 82/100 final-artwork gate.
